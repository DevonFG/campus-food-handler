# Campus Food Finder

Campus Food Finder is an ENGR 110 group project at Oregon State University. We’re building a website to help students on the Corvallis campus find free groceries and ready-to-eat meals that fit around their class schedules.

The prototype is designed to list 5–10 campus and nearby food resources. Students can filter by day, time, and food type, then check the location, pickup hours, eligibility, what to bring, and when the information was last verified.

## Prototype scope

Listings are entered manually, and sample listings are clearly labeled. The app is designed to run in the browser and be hosted on GitHub Pages.

## AI use

100% of the app’s code is AI-generated. Our team defines the requirements, guides development through prompts, and is responsible for reviewing and testing the app.
